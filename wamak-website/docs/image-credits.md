# Image credits

No third-party photographs are used. The build environment blocks stock-image hosts, and the brief
forbids images implying WAMAK facilities, so every slot renders a generated `MaterialPlaceholder`
(original SVG, no licence needed) until real WAMAK photography is supplied.

The world map dots are generated from `dotted-map` (MIT), which bundles public-domain country outlines.

When real or licensed photos are added, list each one here: file, source, photographer, licence.
